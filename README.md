# RadioVTV

Радиостанция «Дыхание ВТВ» — концепт автономного полевого радиомаяка для заполярных мест, где не ловит телефон, нет интернета и обычный эфир растворяется в шуме.

Проект описывает самодельную средневолновую станцию на 1219 кГц: простая химическая энергия из магниевых ячеек в бочках, водяное заземление, провод-антенна по соснам, гермобокс с электроникой и плейлист без рекламы и повторов.

Главный документ:

- `power-system-zapolyarye-transmitter-guide.html` — практическое руководство по установке, питанию, антенне, заземлению, передатчику и подготовке аудио.

Идея проекта — сделать инженерный северный челлендж: природа, рыбалка, чистая голова, работа руками и свой живой сигнал в местах, где обычно молчит всё.
